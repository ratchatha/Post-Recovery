# Post-Recovery Checklist

โปรแกรมช่วยตรวจและตั้งค่าเครื่องโน้ตบุ๊ก Windows หลังทำ Recovery ครบ 9 ขั้นตอนในที่เดียว
ทำงานผ่าน PowerShell โดยมีไฟล์ `.bat` เป็นตัวเปิด และแสดงผลเป็นภาษาอังกฤษทั้งหมด
เพื่อให้ใช้ได้กับ terminal ที่ไม่รองรับภาษาไทย

## ไฟล์ในโปรแกรม

| ไฟล์ | หน้าที่ |
|---|---|
| `PostRecovery.bat` | ตัวเปิดโปรแกรม ขอสิทธิ์ Administrator ให้อัตโนมัติ |
| `PostRecovery.ps1` | ตัวโปรแกรมหลัก |

## ความต้องการของระบบ

- Windows 10 / 11
- Windows PowerShell 5.1 (มีมากับ Windows อยู่แล้ว)
- สิทธิ์ Administrator
- อินเทอร์เน็ต (สำหรับขั้นตอนที่ 1, 2 และการซิงค์เวลา)
- `winget` (ไม่บังคับ ใช้ติดตั้ง Chrome / Adobe Reader / Intel DSA อัตโนมัติ)

## วิธีใช้

1. แตกไฟล์ zip ออกมาเป็นโฟลเดอร์ (อย่ารันจากในไฟล์ zip โดยตรง)
2. ดับเบิลคลิก `PostRecovery.bat` แล้วกด Yes เมื่อ Windows ขอสิทธิ์ Administrator
3. เลือกขั้นตอน
   - กด Enter เพื่อทำทั้ง 9 ขั้นตอน
   - หรือพิมพ์หมายเลข เช่น `1,3,8` เพื่อทำเฉพาะบางขั้นตอน
4. ตอบคำถามบนหน้าจอ (Y/N) ตามต้องการ
5. เมื่อจบจะแสดงสรุปผล และบันทึกรายงานเป็นไฟล์ `.txt` ไว้ในโฟลเดอร์เดียวกับโปรแกรม

เรียกใช้จาก PowerShell โดยระบุขั้นตอนตรงๆ ได้ด้วย

```powershell
powershell -ExecutionPolicy Bypass -File .\PostRecovery.ps1 -Steps 1,8
```

## 9 ขั้นตอนที่โปรแกรมทำ

| ขั้น | หัวข้อ | โปรแกรมทำอะไร | ต้องให้ผู้ใช้ช่วย |
|---|---|---|---|
| 1 | Windows Update / Intel Driver Support | ค้นหาและติดตั้งอัปเดตค้าง, ตรวจ Intel Driver & Support Assistant (เฉพาะเครื่อง Intel) | ยืนยันการติดตั้ง, รีสตาร์ทเมื่อจำเป็น |
| 2 | โปรแกรมพื้นฐาน | ตรวจ Google Chrome, Microsoft 365, Adobe Acrobat/Reader และติดตั้ง Chrome กับ Adobe ผ่าน winget | Microsoft 365 ต้องติดตั้งและล็อกอินเอง |
| 3 | กล้อง / เสียง / เวลา / ภาษา | ตรวจอุปกรณ์กล้องและเสียง, ซิงค์เวลา, ตรวจเขตเวลา (ประเทศไทย), ตรวจภาษาไทย/อังกฤษ | ดูภาพกล้อง, ฟังเสียงทดสอบ, ลองกดสลับภาษา |
| 4 | ชื่อเครื่อง = Barcode | ตั้งค่า Device name (Settings > About) ตาม Barcode | สแกน/พิมพ์ Barcode, รีสตาร์ท |
| 5 | Partition | แสดงไดรฟ์ทั้งหมด ย่อไดรฟ์ C: แล้วสร้างไดรฟ์ข้อมูลใหม่ | ระบุขนาด C: และชื่อไดรฟ์ใหม่ |
| 6 | Access work or school | ตรวจการเชื่อมต่อองค์กร (Azure AD / Domain / MDM) และถอด Azure AD ได้ | บัญชีทั่วไปต้องกด Disconnect เอง (โปรแกรมเปิดหน้า Settings ให้) |
| 7 | BitLocker | ตรวจเฉพาะเครื่อง DELL และ ThinkPad ถ้าเปิดอยู่จะแสดงผลสีแดง | ตรวจด้วยตาที่หน้า Control Panel (ถ้าต้องการ) |
| 8 | แบตเตอรี่ | วัดสุขภาพแบตเตอรี่ (Full Charge / Design Capacity) ต่ำกว่า 60% แจ้งว่าควรเปลี่ยน | เลือกร้านและราคาเอง (โปรแกรมเปิดผลค้นหา Google / Lazada / Shopee ให้) |
| 9 | ล้างประวัติ | ล้างประวัติเว็บและประวัติดาวน์โหลดของ Chrome/Edge, ประวัติค้นหา Explorer/Run, ไฟล์ล่าสุด, ถังขยะ | ยืนยันก่อนล้าง |

## ความหมายของสถานะในรายงาน

| สถานะ | ความหมาย |
|---|---|
| `OK` | ผ่าน |
| `WARN` | ควรตรวจสอบเพิ่ม หรือรอรีสตาร์ท |
| `FAIL` | ไม่ผ่าน ต้องแก้ไข |
| `INFO` | ข้อมูลทั่วไป / ข้ามขั้นตอน |

## ข้อควรระวัง

- **ขั้น 4:** Windows จำกัดชื่อเครื่องไม่เกิน 15 ตัวอักษร ใช้ได้เฉพาะ A-Z, 0-9 และ `-` และห้ามเป็นตัวเลขล้วน ถ้า Barcode ไม่เข้าเงื่อนไข โปรแกรมจะไม่เปลี่ยนชื่อให้
- **ขั้น 5:** การย่อและสร้างพาร์ทิชันกู้คืนไม่ได้ ควรใช้กับเครื่องที่ยังไม่มีข้อมูลสำคัญ
- **ขั้น 6:** ถ้าเครื่องผูกกับ Azure AD และกำลังล็อกอินด้วยบัญชีองค์กร การสั่งถอดอาจทำให้เข้าเครื่องไม่ได้
- **ขั้น 9:** ลบแล้วกู้คืนไม่ได้ ไม่ลบ Bookmark และรหัสผ่าน ไม่ลบไฟล์ใน Downloads เว้นแต่เลือกเอง และไม่ล้าง Firefox (Bookmark เก็บในไฟล์เดียวกับประวัติ) ถ้า Chrome เปิด Sync ประวัติอาจกลับมาจากบัญชีได้
- ถ้ายกระดับสิทธิ์ด้วยรหัสของแอดมินคนอื่น ประวัติที่ล้างจะเป็นของบัญชีแอดมินนั้น ไม่ใช่บัญชีที่ใช้งานอยู่

## ข้อจำกัด

- โปรแกรมไม่ดึงราคาหรือชื่อร้านเปลี่ยนแบตเตอรี่ให้ เพราะต่างกันตามรุ่น จึงเปิดหน้าค้นหาให้แทน
- การตรวจกล้อง เสียง และการสลับภาษา ต้องให้คนช่วยยืนยัน
- ผลของขั้น 7 ใช้ `Get-BitLockerVolume` (ถ้าไม่มีจะใช้ `manage-bde`) ซึ่งอาจใช้ไม่ได้บน Windows Home บางรุ่น

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| ขึ้นว่าไม่ได้รันแบบ Administrator | ปิดแล้วเปิดใหม่ผ่าน `PostRecovery.bat` และกด Yes ตอนขอสิทธิ์ |
| รันแล้วหน้าต่างปิดทันที | เปิด Command Prompt แล้วรัน `PostRecovery.bat` จากในนั้นเพื่อดูข้อความ error |
| ไฟล์ถูกบล็อก / SmartScreen เตือน | คลิกขวาที่ไฟล์ > Properties > ติ๊ก Unblock หรือกด More info > Run anyway |
| ค้นหาอัปเดตนาน | ปกติ อาจใช้เวลาหลายนาที โดยเฉพาะเครื่องที่เพิ่ง Recovery |
| ล้างประวัติ Chrome/Edge ไม่ครบ | ปิดเบราว์เซอร์ให้หมดแล้วรันขั้น 9 ใหม่ |

## รายงานผล

เมื่อจบการทำงาน โปรแกรมบันทึกไฟล์ `PostRecovery_Report_<ชื่อเครื่อง>_<วันที่เวลา>.txt` ไว้ในโฟลเดอร์เดียวกับโปรแกรม
(ถ้าโฟลเดอร์เขียนไม่ได้ เช่น USB ที่ล็อกการเขียน จะบันทึกที่โฟลเดอร์ Temp แทน)
